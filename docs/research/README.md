# Research repository

This is where synthesised research lives. Raw recordings, consent forms and personal data **do not** go in this repo, because it is public and POPIA applies.

## Structure

```text
docs/research/
  plan.md        research questions, method, participants, timeline
  log.md         sessions run: anonymised ID (P1, P2…), date, method
  insights.md    insight headline · evidence (quotes, frequency "4 of 6") · so-what
  desk/          secondary research with source links and the source tier
```

## Rules

- **Anonymise everything here.** Use P1, P2 and so on, with no names, emails or faces. Daan is a participant too, so his data follows the same rule.
- Training and wellness data (HRV, sleep, resting HR, activities) is personal health information. Describe patterns, never paste raw values or screenshots of real accounts.
- Every insight shows its evidence and frequency. "Users want X" with no count is not an insight.
- Mark desk research claims with their source tier (see the portfolio's `docs/sources.md`).
